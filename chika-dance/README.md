# 初音未来 × 书记舞（60 秒程序化动画）

一个纯代码生成的 2D 动画：初音未来风格的 Q 版角色，跳《辉夜大小姐想让我告白》片尾“书记舞”的招牌动作，时长 60 秒（128 BPM × 32 小节）。

- `index.html` — 网页版。打开即可播放，带进度条、段落跳转、静音开关。角色、舞步、背景特效和配乐都在这一个文件里：
  - 角色用 Canvas 2D 逐帧绘制，四肢由双骨骼 IK 驱动，双马尾用延迟采样做甩动。
  - 舞步分 10 段：登场 → 指尖闪烁 → 叉腰扭胯 → 绕拳甩臂 → 举手摆荡 → 转身回眸 → 托腮卖萌 → 侧步拍手 → 再来一次 → 定格。
  - 配乐是原创合成（kick / clap / hat + 锯齿波贝斯 + 脉冲波和弦 + 方波主旋律），不是原曲。
- `render.mjs` — 用无头 Chromium 逐帧离线渲染，并用 ffmpeg 合成 MP4：

  ```bash
  node render.mjs                       # 输出 miku-chika-dance.mp4（1280×720，30 fps，60 s）
  node render.mjs --preview 1,7.2,30    # 只导出几张 PNG 静帧
  W=1920 H=1080 CRF=16 node render.mjs  # 自定义分辨率 / 画质
  ```

- `miku-chika-dance.mp4` — 渲染好的成片。

角色属于初音未来风格的同人绘制，舞步为对书记舞的再编排。
