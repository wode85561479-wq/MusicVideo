# 制作记录

## 阶段 A：环境与素材（详见 `阶段A_环境与素材确认.md`）
- 无 GPU、无生成服务密钥；HuggingFace 与 PyTorch 官方源被拦截。确定改用"参考图关键画面 + 自研 2.5D 水墨合成引擎"的路线。
- Real-ESRGAN 只有 PyTorch 权重：编写 .pth 解析器，把 SRVGGNetCompact 重建为 ONNX（首次因 ONNX IR 版本 14 过高而失败，降到 IR 8 后成功）。

## 音频分析
- 结构新颖度曲线第一次全为零：棋盘核符号写反，被截断为 0。修正后得到 16 个结构边界。
- 人声区间用 REPET-SIM 前景分离估计，并用前景频谱图目视核对（颤音谐波可见）。速度估计 129.2 BPM，很可能是约 64.6 BPM 慢板的双倍。
- 全曲最响 ≈202s；138–143s 近乎静默；253.5s 后为静音尾巴。

## 镜头迭代（静帧预览 → 修正）
- 墨迹显影公式方向写反（t=0 时人物已完整可见），PlateStack / InkMountains / ink_dissolve 三处一起修正。
- 程序化山峦三次迭代：① 三角形、对称、透明叠穿 → ② 披麻皴像条形码、团块细碎 → ③ 不对称域扭曲峰形 + 纸白遮挡后山 + 平滑洗染 + 局部褶皱。
- 蛛网从"工程图式同心螺旋"改为手作感：半径抖动、断丝、浓淡不一、外延挂丝。
- 浅色宣纸上的月亮不可见 → "烘云托月"。
- 远景"上摇"因远层视差小，月亮无法入画 → 相机加入 pan（摇镜是整体平移，物理上本就没有视差）。
- SH06 取景越过画作边界 → PlateStack 自动钳制取景中心。
- SH14、SH23、SH24 人物出画或贴边 → 重算构图。
- SH31 剥落从方块马赛克重做为有机斑块，碎片取原位颜色，底层改为佛窟岩壁。
- SH33 写实野猪：OpenCV 风格化会把毛发烧成黑斑，弃用；改为轻度保边平滑 + 墨线。

## 样板镜头 SH08 验证（阶段 D）
- 180 帧 / 7.5s / 1920×1080 / 24fps / H.264，单进程 1.09 秒/帧。
- 平均帧间运动 0.85，零冻结帧，最大亮度跳变 0.16（无闪烁）。
- 时序抽帧确认：相机横移与推进、近中远景视差、雾带流动、花瓣飘落、紫蛛儿在 2–4 秒间由墨迹凝聚成形。
